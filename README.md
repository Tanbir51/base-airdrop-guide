# Base Airdrop Eligibility Guide

This repository is my personal learning log for participating in the Base ecosystem.

## Eligibility Checklist

- [ ] Connect a supported wallet
- [ ] Bridge assets to Base
- [ ] Make transactions on Base
- [ ] Interact with Base ecosystem applications
- [ ] Provide liquidity where appropriate
- [ ] Complete eligible ecosystem quests
- [ ] Maintain a record of on-chain activity

## Important Notes

Airdrop eligibility is determined by each project's own rules.
Completing these activities does not guarantee any future token allocation.

I am using this repository to track my learning and on-chain activities.
